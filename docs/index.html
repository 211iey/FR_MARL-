$$c_t = 0.00015 \times \sum_{i=1}^{14}|w_i^{new} - w_i^{old}|$$ $$r_t^{net} = \mathbf{w}_t^\top \mathbf{ret}_t - c_t$$

포트폴리오 가치 업데이트

$$P_t = P_{t-1} \cdot e^{r_t^{net}}$$

로그수익률을 지수변환하여 복리 효과 정확히 반영.

Reward: Differential Sharpe Ratio (DSR)

Sharpe Ratio를 매 스텝 보상으로 분해할 수 있는 유일한 방법. 논문 수식 3.4~3.7.

지수이동평균 업데이트 ($\eta = 1/252$)

$$\delta_t = r_t - A_{t-1}, \qquad \delta_t^{(2)} = r_t^2 - B_{t-1}$$ $$A_t = A_{t-1} + \eta\,\delta_t \qquad\text{(수익률 EMA)}$$ $$B_t = B_{t-1} + \eta\,\delta_t^{(2)} \qquad\text{(수익률² EMA)}$$

DSR 계산

$$\text{DSR}_t = \frac{B_{t-1}\,\delta_t - \tfrac{1}{2}\,A_{t-1}\,\delta_t^{(2)}}{\bigl(B_{t-1} - A_{t-1}^2\bigr)^{3/2}}$$ $$\text{reward}_t = \text{clip}(\text{DSR}_t,\;{-10},\;{+10})$$

관계

$$\text{Sharpe} \approx \frac{A_T}{\sqrt{B_T - A_T^2}} \cdot \sqrt{252} \qquad\Rightarrow\qquad \sum_{t=1}^T \text{DSR}_t \propto \text{Sharpe}_T$$

DSR의 누적합이 최종 Sharpe와 비례하므로 매 스텝 최적화가 곧 Sharpe 최대화.

PPO 알고리즘

목적함수 (Clipped Surrogate)

$$r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}$$ $$L^{\text{CLIP}}(\theta) = \mathbb{E}_t\!\left[\min\!\left(r_t(\theta)\hat{A}_t,\ \text{clip}\!\left(r_t(\theta),1{-}\epsilon,1{+}\epsilon\right)\hat{A}_t\right)\right]$$

$\epsilon = 0.25$, 정책 업데이트 보수적 제한.

HMM 시장 국면 감지

Gaussian HMM

관측 변수: (kospi 수익률, vkospi) → StandardScaler
$$P(o_t | z_t = k) = \mathcal{N}(o_t;\;\mu_k,\;\Sigma_k)$$ $$P(z_t = j | z_{t-1} = i) = A_{ij} \quad\text{(전이 행렬)}$$

$n\_regimes = 3$ (Bull / Neutral / Bear 추정)
