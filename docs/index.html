Reward: Differential Sharpe Ratio (DSR)

Sharpe Ratio를 매 스텝 보상으로 분해할 수 있는 유일한 방법. 논문 수식 3.4~3.7.

지수이동평균 업데이트 ($\eta = 1/252$)

$$\delta_t = r_t - A_{t-1}, \qquad \delta_t^{(2)} = r_t^2 - B_{t-1}$$ $$A_t = A_{t-1} + \eta\,\delta_t \qquad\text{(수익률 EMA)}$$ $$B_t = B_{t-1} + \eta\,\delta_t^{(2)} \qquad\text{(수익률² EMA)}$$

DSR 계산

$$\text{DSR}_t = \frac{B_{t-1}\,\delta_t - \tfrac{1}{2}\,A_{t-1}\,\delta_t^{(2)}}{\bigl(B_{t-1} - A_{t-1}^2\bigr)^{3/2}}$$ $$\text{reward}_t = \text{clip}(\text{DSR}_t,\;{-10},\;{+10})$$

관계

$$\text{Sharpe} \approx \frac{A_T}{\sqrt{B_T - A_T^2}} \cdot \sqrt{252} \qquad\Rightarrow\qquad \sum_{t=1}^T \text{DSR}_t \propto \text{Sharpe}_T$$

DSR의 누적합이 최종 Sharpe와 비례하므로 매 스텝 최적화가 곧 Sharpe 최대화.

경제학 관점에서는 …

DSR은 Sharpe Ratio의 1차 증분(marginal increment)으로 해석된다 (Moody & Saffell, 2001). 누적합 $\sum_t \text{DSR}_t$ 가 기간말 Sharpe에 비례하므로, 에이전트가 기대 보상을 최대화하는 것은 사후 Sharpe를 최대화하는 것과 정확히 등가다. 즉 평균-분산 전통과 직접 호환되면서, 단일 단계에서 미분 가능한 신호로 쪼개진다는 것이 장점이다.

PPO 알고리즘

목적함수 (Clipped Surrogate)

$$r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}$$ $$L^{\text{CLIP}}(\theta) = \mathbb{E}_t\!\left[\min\!\left(r_t(\theta)\hat{A}_t,\ \text{clip}\!\left(r_t(\theta),1{-}\epsilon,1{+}\epsilon\right)\hat{A}_t\right)\right]$$

$\epsilon = 0.25$, 정책 업데이트 보수적 제한.

경제학 관점에서는 …

Clipped surrogate의 $1 \pm \epsilon$ 은 정책 업데이트에 대한 신뢰구간(trust region) 제약이다. 정책이 한 번에 크게 튀지 못하도록 막아 학습이 발산하지 않도록 한다 — Bayesian updating이나 부드러운 정책 업데이트(adaptive learning)와 같은 설계 철학이다. 엔트로피 보너스 $c_2 H[\pi]$ 는 확률 분포를 일정 수준 이상 퍼지게 유지하여 조기 수렴을 방지하는 역할을 한다.

HMM 시장 국면 감지

Gaussian HMM

관측 변수: (kospi 수익률, vkospi) → StandardScaler
$$P(o_t | z_t = k) = \mathcal{N}(o_t;\;\mu_k,\;\Sigma_k)$$ $$P(z_t = j | z_{t-1} = i) = A_{ij} \quad\text{(전이 행렬)}$$

$n\_regimes = 3$ (Bull / Neutral / Bear 추정)

State 주입 방식

Train 데이터만으로 HMM 학습
↓ 각 Round마다 재학습 (미래 누출 방지)
$p_t^{HMM} = \text{softmax}(P(z_t|o_{1:t}))$
↓ State의 마지막 3차원으로 concat
$s_t = [\ldots,\; p_t^{bull},\; p_t^{neutral},\; p_t^{bear}]$
경제학 관점에서는 …

3-state HMM은 Hamilton(1989)의 Markov regime-switching 모형 계보에 있다. KOSPI 수익률과 VKOSPI만으로 Calm · Normal · Turbulent 국면을 비지도 학습으로 식별하며, Ang & Bekaert(2002)의 regime-dependent 자산배분 문헌과 같은 맥락이다. 차이는 여기서 regime posterior를 RL policy의 입력 feature로 직접 공급한다는 점 — 규칙 기반 배분 대신 정책이 국면별 대응을 스스로 학습한다.

B. Multi-Agent IPPO — λ sweep 진행 중

독립 PPO 5개 에이전트가 동시에 학습. 서로의 포트폴리오 비중에 대한 상관/거리 기반 페널티 $\lambda$ 를 부여.

최종 보상
$$r_t^{\text{agent}_i} = \text{DSR}_t^{\text{agent}_i} + \lambda \cdot \text{diversity}_t$$
  • Correlation 모드: diversity = $-\overline{\text{corr}}(w^{(i)}, w^{(j)})$
  • TV 모드: diversity = $\tfrac{1}{2}\overline{\lVert w^{(i)} - w^{(j)} \rVert_1}$

부분 결과 (Train 2013 ~ 2019 / Val 2020 / Test 2021 고정)

0.0correlation 0.361−12.4% 0.006−0.026
0.0tv 0.359−12.4% 0.006−0.021
0.5correlation 0.298−12.6% 0.010+0.468
0.5tv 0.348−12.4% 0.007+0.147

관찰 1. λ=0.0 (페널티 없음) 에서 이미 에이전트 간 평균 상관이 −0.026 (거의 독립) — 독립 seed + 독립 PPO 학습만으로도 자연스런 분산이 형성된다.
관찰 2. λ를 0.5로 높이면 오히려 상관이 양으로 증가하고 Sharpe가 하락 — 페널티 부호·스케일 재점검 필요. 현재 λ ∈ {0.1, 0.2, …, 0.9} 나머지 sweep 진행 중이며 완료 후 재분석 예정.

※ Single-Agent 대비 MARL의 Turnover (≈0.006~0.010)가 두 자릿수 이상 낮게 나타남. VecNormalize 도입 전 데이터로, 현재 reward scale 정규화 후 재실험 중.
